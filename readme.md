Giới thiệu

Đây là tài liệu hướng dẫn và giải thích về code trong dự án.

Cấu trúc thư mục

tx_his.py: Lấy lịch sử giao dịch blockchain theo từng khoảng block và xuất dữ liệu ra CSV.

blacklist_token: Danh sách các token không cần lấy.

Chức năng chính

Lấy lịch sử giao dịch từ blockchain với mỗi khoảng block.

Lưu lịch sử giao dịch vào file csv.


API

GET /history: Lấy lịch sử giao dịch của user.

POST /monitor: Bật/tắt monitor giao dịch.

GET /logs: Lấy log giao dịch theo thời gian thực.
